# Reflection Circle — Prototypes

Interactive, teacher-facing WhatsApp mockups for the SESEMAT facilitated
reflection-circle concept (Learning Equality).

Open **index.html** for a landing page linking all four prototypes, or open
any file directly:

- `index.html` — landing page (links to everything)
- `all-scenarios.html` — the full prototype (all four scenarios via tabs)
- `scenario-0.html` — Join & weekly prompt
- `scenario-1.html` — Private reflection
- `scenario-2.html` — Cross-circle digest

All names, numbers and avatars are placeholders. These are clickable
proof-of-concept mockups for co-design feedback; nothing connects to a real
WhatsApp account.

## Hosting (GitHub Pages)

Push this folder to a GitHub repository, then in the repo go to
**Settings → Pages** and set the source to the **main** branch, **/(root)**.
The site publishes at `https://<user>.github.io/<repo>/`, and each file is its
own shareable link, e.g. `.../scenario-1.html`.
